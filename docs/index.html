Windrose Server
auf Knopfdruck

Kein .bat-Skript, kein Notepad. Starte, stoppe und konfiguriere deinen Windrose Dedicated Server mit einer modernen Desktop-App.

⬇ Installer herunterladen GitHub

Was drin ist

🖥️

Server-Steuerung

Server starten, stoppen und neu starten per Klick. Uptime-Anzeige, Invite-Code kopieren, Spieler-Zähler — alles auf einen Blick im Dashboard.

📋

Log-Viewer

UE5-Rohlogs werden in lesbare Ereignisse gefiltert. Boot-Noise ausgeblendet, Key-Events farbig hervorgehoben — mit Raw-Toggle für die volle Ausgabe.

🌍

Welten-Manager

Welten mit eigenem Alias benennen statt Hex-IDs merken. Backups anlegen, Versionen wiederherstellen, Welten importieren — alles mit integrierter Validierung.

⚙️

Config-Editor

ServerDescription.json und WorldDescription.json komfortabel bearbeiten. Felder gesperrt wenn Server läuft — Datenverlust durch Editieren im Betrieb ausgeschlossen.

Voraussetzungen

  • ✓ Windows 10 oder 11 (64-bit)
  • ✓ Microsoft WebView2 Runtime (auf Win11 vorinstalliert)
  • ✓ Windrose Dedicated Server via Steam (App-ID 4129620)
  • ✓ Steam-Installation im Standard-Pfad (oder manuell konfigurierbar)
